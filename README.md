# コンビニダイエット (Android)

自分の DeepSeek API キーを端末内に暗号化保存して使う、個人利用向けのAndroidアプリです。

## 今回の監査・修正版 v2.1.0

コード全体を見直し、単なる機能追加ではなく、商品データ・AI通信・栄養計算・画面処理を整理しました。

### 主な修正
- AndroidXを使用しているのに無効化されていた設定を修正 (`android.useAndroidX=true`)
- minSdk 26で利用できない `String.isBlank()` 依存を廃止
- Android 12〜14で問題になり得るKeystoreの `setUnlockedDeviceRequired(true)` をAndroid 15以降だけで使うよう修正
- 商品保存をSharedPreferencesの巨大JSONからSQLiteへ移行
- 旧版の手登録商品はSQLiteへ自動移行
- 初期商品DBを空にせず、コンビニ公式ページで確認した実商品20件を同梱
- DeepSeek Searchで公式コンビニサイトを検索し、不足商品・更新商品をSQLiteへキャッシュ
- Search結果URLを公式ドメインのHTTPS URLか再検証してから採用
- 価格を正式なDB項目として追加
- 栄養値が不明な項目は0ではなくNULL/「不明」で保持
- 今日の残り栄養も、不明商品を含む項目は「算出不可」と表示
- お気に入りをAI文章だけでなく、判別できた商品IDとも紐付け
- 商品DBから「今日食べた」に直接追加可能
- 撮影画像は解析終了後にキャッシュから削除
- Android 15以降のエッジ・ツー・エッジ表示を考慮し、システムバー/ノッチのInsetsを反映
- 小画面では余白・文字を自動調整しつつ、タップ領域は約48dpを維持

詳細は `AUDIT.md` を参照してください。

## 商品DB

初回起動時から使えるように、実商品20件を `app/src/main/assets/seed_products.json` に同梱しています。現在の内訳はセブン-イレブン10件、ファミリーマート5件、ローソン5件です。

アプリ内の「公式サイトから商品DBを更新」を使うと、DeepSeek Search APIで以下の公式サイトだけを検索します。

- セブン-イレブン: `sej.co.jp`
- ファミリーマート: `family.co.jp`
- ローソン: `lawson.co.jp`
- ミニストップ: `ministop.co.jp`

検索結果はアプリ側でHTTPSと公式ドメインを再検証し、AIには「ページに無い数値を推測しない」「不明はnull」と指示して構造化します。採用した商品には情報元URLと確認日を保存します。

**注意:** 公式サイトに掲載されていることと、目の前の店舗に在庫があることは別です。在庫を保証する機能ではありません。「これ売ってない」から保存済みDB内の代替候補を探せます。

## DeepSeek使用量・料金表示
- Chat APIのレスポンス `usage` をそのまま使い、入力トークン（キャッシュ命中/非命中）、出力、推論、合計を端末内で記録します。
- Search APIはHTTP 200かつ検索結果が1件以上返った成功リクエストだけを課金回数として記録します。
- 料金表は2026-10-23時点のDeepSeek公式料金を実装しています。Chatはピーク/オフピークがあるため、過少表示を避ける目的で「オフピーク〜ピーク」の範囲表示にしています。
- Searchは1,000成功リクエストあたりUS$0.75として集計します。
- 円表示は設定画面のUSD/JPY換算レートで参考換算します（初期値150円/USD）。為替レートの自動取得は行いません。
- 「今月リセット」は当月表示だけを0にし累計は残します。「累計リセット」は累計だけを0にし今月表示は残します。
- リセットはDeepSeekアカウントの請求・残高・利用履歴を変更しません。
- このアプリから発生した通信だけを数えるため、同じAPIキーをPCや別アプリで使った分は集計されません。

## APIキーのセキュリティ
1. APIキーをソース、resources、BuildConfig、Gradleへ埋め込みません。
2. Android KeystoreのAES-256-GCM鍵で暗号化します。
3. StrongBox対応端末ではStrongBoxを試し、非対応でも平文鍵へフォールバックしません。
4. 暗号化データは `noBackupFilesDir` にAtomicFileで保存します。
5. APIキー設定画面は `FLAG_SECURE` でスクリーンショット/最近の画面プレビューを抑止します。
6. APIキー欄はパスワード表示、Autofill除外、キーボード個人学習抑制を設定します。
7. アプリのバックアップを無効化しています。
8. APIキーは `Authorization: Bearer ...` ヘッダーだけで使用し、会話本文や商品DBへ入れません。
9. APIキーを送るホストは `api.deepseek.com` に固定します。
10. HTTP平文通信とHTTPリダイレクトを拒否します。
11. APIキーをログ出力する処理はありません。

### 外部通信について
DeepSeekを使う以上、APIキーとAIへ送る相談内容はDeepSeekへ送信されます。商品DB更新時には検索クエリと、検索で取得した公式ページ本文もDeepSeekへ送られます。

OCR/バーコードにはバンドル版Google ML Kitを使用します。アプリから撮影画像や認識結果をGoogleへ送る独自処理はありませんが、ML Kit SDK自体が端末・アプリ情報、性能指標などの診断/利用統計を収集する場合があります。APIキーはML Kitへ渡しません。

## 権限
- `CAMERA`: 栄養表示・バーコード撮影。初回起動時に許可を確認します。
- `INTERNET`: DeepSeek Chat/Search。Androidの通常権限なので許可ダイアログはありません。
- 位置情報、マイク、連絡先、常時ストレージアクセスは要求しません。

## 現在の限界
- コンビニ公式サイトの掲載商品は、地域・店舗・時期によって実際の取扱いと一致しない場合があります。
- OCRは撮影条件や印字によって誤認識します。商品ラベルの実表示を最終確認してください。
- 「糖質」と「糖類」は同じ指標ではありません。公式表示が無い値は推測しません。
- AIの文章中の合計値は補助情報です。端末内の「今日の記録」は構造化DB値をアプリ側で加算します。
